# Homebrew Tap

Personal Homebrew tap for CLI tools.

## Install

```bash
brew tap e1sidy/tap
```

## Available Formulae

### claude-usage

Real-time CLI monitor for Claude Code token usage, costs, and session limits.

```bash
# Install
brew install claude-usage

# Enable notifications every 15 min
brew services start claude-usage

# Stop notifications
brew services stop claude-usage
```

See [claude-usage](https://github.com/e1sidy/claude-usage) for full docs.
